# 🛍️ NovaCart — E-Commerce Frontend

A modern, responsive e-commerce frontend built using **HTML, CSS, and JavaScript**. NovaCart allows users to browse products, search and filter items, manage a shopping cart, add products to a wishlist, apply coupons, and complete a demo checkout flow.

## 🌐 Live Demo

**NovaCart E-Commerce Frontend:**
https://vanshika2723.github.io/NovaCart-E-Commerce-Frontend/

---

## ✨ Features

### 🛍️ Product Browsing

* Responsive product grid
* Product categories
* Product details modal
* Product ratings and reviews
* Product badges such as Sale, New, Popular and Trending
* Real product images
* Product sorting

### 🔎 Search & Filters

* Product search
* Category filtering
* Sorting options
* Search result count
* Empty search-result state
* Clear search functionality

### 🛒 Shopping Cart

* Add products to cart
* Increase/decrease product quantity
* Remove products from cart
* Automatic subtotal calculation
* Delivery charge calculation
* Discount calculation
* Total price calculation
* Empty cart state
* Cart data saved using LocalStorage

### ❤️ Wishlist

* Add/remove products from wishlist
* Wishlist counter
* Wishlist modal
* Move wishlist products to cart
* Wishlist data saved using LocalStorage

### 🎟️ Coupon System

* Coupon code functionality
* Discount calculation
* Demo coupon: `NOVA50`
* Coupon success/error messages

### 💳 Checkout

* Customer information form
* Address details
* Payment method selection
* Order summary
* Discount and delivery calculation
* Demo order placement
* Order confirmation modal
* Automatically generated order ID

### 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/vanshika2723/NovaCart-E-Commerce-Frontend.git
```

### 2. Open the project

```bash
cd NovaCart-E-Commerce-Frontend
```

### 3. Run the project

Open `index.html` in your browser.

For the best development experience, use **VS Code with Live Server**.

## 💾 LocalStorage

NovaCart uses browser LocalStorage to preserve shopping data.

Stored information includes:

```text
cart
wishlist
```

This allows cart and wishlist items to remain available even after refreshing the page.
