# Datheon Full Stack Web Development Internship

## About the Internship
This repository contains all four projects completed during the Datheon Full Stack Web Development Internship.

The projects demonstrate practical skills in frontend development, JavaScript, application development, API integration, CRUD operations, and responsive UI design.

## Completed Tasks

### Task 1: Personal Developer Portfolio & Project Showcase
- Designed and developed a modern personal developer portfolio.
- Created a responsive layout.
- Showcased personal profile and projects.

### Task 2: Dynamic Task Manager & Productivity Tracker (CRUD)
- Developed an interactive task management application.
- Implemented Create, Read, Update, and Delete (CRUD) functionality.
- Used browser localStorage for data persistence.

### Task 3: Real-Time Weather Forecast & Climate Telemetry App
- Integrated third-party REST APIs.
- Implemented asynchronous API requests.
- Added error handling and dynamic UI updates.

### Task 4: E-Commerce Product Catalog & Interactive Shopping Cart
- Developed an interactive product catalog.
- Implemented shopping cart functionality.
- Managed product quantities and cart state.
- Created an interactive checkout drawer.
